# Epguides API

TV show, season and episode data over REST and the Model Context Protocol.

- [Public REST API and interactive schema](https://epguides.frecar.no/docs)
- [MCP endpoint](https://epguides.frecar.no/mcp) with tool discovery through `tools/list`
- [Getting started](https://epguides-api.readthedocs.io/)

For local development, run `make setup` then `make up`. Use `make help` for supported commands and `make urls` for local service addresses. The API runs without a public API key.
